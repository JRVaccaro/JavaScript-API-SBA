# JavaScript Web Design API SBA
A simple single-page web application that uses JavaScript, modules, and an external API to search, create, and update posts. This project demonstrates using asynchronous JavaScript with fetch, async/await, and API requests.
## User Stories
* As a user, I want to search through posts so I can quickly find information.

* As a user, I want to create a new post so I can add new content.

* As a user, I want to update a post so I can make changes to existing content.

## Features
*Search posts using data from an API.

* Create new posts using a POST request.

* Update posts using a PATCH request.

* Responsive design with HTML and CSS.
 


## Future Work
- Add more styling and animations to improve the user experience.

- Add the ability to delete posts.

- Add more ways to filter and organize posts.
